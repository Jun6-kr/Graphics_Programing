## Implementation

### Transform 클래스 추가

- 물체의 위치·회전·크기를 관리하는 `Transform` 클래스 추가
- `position`, `rotation`, `scale`의 기본값을 각각 `Vector3::Zero`, `Vector3::Zero`, `Vector3::One`으로 설정
- `Transform::Update()`에서 Scale, Rotation, Translation Matrix를 결합해 World Matrix 갱신

```text
World = Scale × Rotation × Translation
```

- 회전값을 기준으로 물체의 `Right`, `Up`, `Forward` 방향을 반환하는 함수 추가
- `Transform.cpp`, `Transform.h`를 Visual C++ Project와 Filter에 등록

### Transform Constant Buffer 생성

- `Renderer`에 `ID3D11Buffer* transformBuffer` 추가
- `D3D11_BIND_CONSTANT_BUFFER`로 Transform Constant Buffer 생성
- CPU에서 자주 갱신할 수 있도록 `D3D11_USAGE_DYNAMIC`과 `D3D11_CPU_ACCESS_WRITE` 사용
- 초기값으로 `Matrix4::Identity` 전달
- Renderer 소멸 시 `SafeRelease()`로 Transform Buffer 해제

### World Matrix 갱신 경로 추가

- `Renderer::UpdateTrnasformBUffer()`에서 `ID3D11DeviceContext::Map()`을 호출해 Buffer의 쓰기 영역 획득
- `D3D11_MAP_WRITE_DISCARD` 방식으로 Mapping
- `std::memcpy()`로 `Matrix4` 데이터를 `mapped.pData`에 복사
- 복사 완료 후 `Unmap()` 호출

```text
Map(transformBuffer, WRITE_DISCARD)
    ↓
memcpy(mapped.pData, worldMatrix.Data(), sizeof(Matrix4))
    ↓
Unmap(transformBuffer)
```

### Vertex Shader World Transform 추가

- HLSL에 `TransformBuffer` Constant Buffer 선언
- Vertex Shader의 `b0` Register에 연결하도록 `register(b0)` 지정
- C++의 행벡터 규약과 맞추기 위해 `row_major matrix world` 사용
- 입력 정점에 World Matrix를 곱해 World 위치 계산

```hlsl
float4 worldPosition = mul(float4(pos, 1), world);
```

## Learned

### Local Transform과 World Matrix

물체별 위치·회전·크기는 Local Transform 정보이며, 이를 하나의 World Matrix로 결합해 정점을 공통 World 공간으로 변환한다. 현재 행벡터 규약에서는 `Scale × Rotation × Translation` 순서로 Matrix를 구성한다.

### CPU에서 GPU로 Transform 전달

C++에서 계산한 World Matrix는 Constant Buffer를 통해 Vertex Shader로 전달할 수 있다. Dynamic Buffer를 Mapping하면 CPU가 쓸 수 있는 메모리 영역을 `mapped.pData`로 받고, 데이터 복사 후 `Unmap()`하여 갱신을 마친다.

### C++과 HLSL의 Matrix 규약 연결

C++ 측 Transform 계산은 행벡터 규약을 사용하고 Vertex Shader도 `mul(vector, matrix)` 형태로 계산한다. HLSL Matrix는 `row_major`로 선언해 코드에서 사용하는 Matrix 배치와 규약을 명시했다.

**Problem**

## Decision

- World Matrix 결합 순서: Scale → Rotation → Translation
- Transform Buffer 용도: `D3D11_BIND_CONSTANT_BUFFER`
- Buffer 사용 방식: `D3D11_USAGE_DYNAMIC`
- CPU 접근 방식: `D3D11_CPU_ACCESS_WRITE`
- 갱신 방식: `Map(D3D11_MAP_WRITE_DISCARD)` → `memcpy()` → `Unmap()`
- Vertex Shader Constant Buffer Slot: `b0`
- Shader Matrix 선언: `row_major`
- Shader Matrix 곱셈: `mul(vector, matrix)`

## Issue

- `transformBuffer`를 Vertex Shader의 `b0` Slot에 연결하는 `VSSetConstantBuffers()` 호출은 아직 확인되지 않는다.
- `UpdateTrnasformBUffer()`를 실제 Draw 흐름에서 호출하는 코드는 아직 확인되지 않는다.
- `RenderCommand` 구조체는 선언되었지만 현재 비어 있다.
- `Transform`의 공개 속성을 변경한 뒤에는 `Update()`를 직접 호출해야 World Matrix에 반영된다.
- `Transform.cpp`와 `Transform.h`에서 현재 코드 페이지와 관련된 MSVC C4819 경고가 발생한다.
- `CreateTansformBuffer`, `UpdateTrnasformBUffer` 함수 이름에 철자 오류가 남아 있다.
- `D3D11_MAP_WRITE_DISCARD`와 `mapped.pData`의 동작 원리를 설명해 달라는 `[도와줘요 CODEX]` 주석이 남아 있다.
