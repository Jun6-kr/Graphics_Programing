## Learned

### Library와 실행 Project의 역할 분리

Engine 코드는 정적 Library로 Build하고, 실제 진입점과 실행 파일은 별도의 Game Project에서 관리할 수 있다. Game Project는 Project Reference를 통해 Engine Library Build와 Link 의존성을 가진다.

### Render Command 기반 Draw 흐름

즉시 `DrawIndexed()`를 호출하는 대신 먼저 World Matrix를 Command 목록에 제출하고, Render 단계에서 목록을 순회하며 Buffer 갱신과 Draw Call을 처리하는 구조를 추가했다.

### Constant Buffer Slot 대응

HLSL의 `register(b0)`와 C++의 `VSSetConstantBuffers(0, ...)`는 같은 Slot 0을 가리킨다. Draw Call 전에 Command의 World Matrix를 Constant Buffer에 기록하면 Vertex Shader가 해당 값을 사용한다.

## Problem / Solved

### Engine 코드와 실행 진입점 결합

**Problem**

기존에는 `CraftEngine` Project가 Engine 구현과 `main`/`WinMain` 진입점을 함께 포함한 Application 형태였다.

**Solved**

`CraftEngine`을 Static Library로 변경하고 실행 진입점은 새 `Game` Application Project로 이동했다. Solution과 Project Reference를 통해 두 Build 대상을 연결했다.

### Transform Buffer가 Shader에 연결되지 않음

**Problem**

Transform Constant Buffer의 생성·갱신 함수는 있었지만 Vertex Shader Slot Binding과 Draw Command 처리 흐름이 연결되지 않았다.

**Solved**

`VSSetConstantBuffers()`로 `b0` Slot에 Buffer를 연결하고, `DrawCommand()`에서 World Matrix 갱신 후 Draw Call을 실행하도록 구성했다.

### Transform Source Encoding 경고

**Problem**

`Transform.cpp`와 `Transform.h`에서 MSVC C4819 Source Encoding 경고가 발생했다.

**Solved**

두 파일을 BOM이 포함된 형식으로 저장했다. Debug x64 전체 Solution Build 결과 경고 0개, 오류 0개를 확인했다.

## Decision

- Engine Build 산출물: Static Library
- 실행 파일 담당 Project: `Game`
- Game과 Engine 연결: Visual C++ Project Reference
- Renderer 접근 방식: 정적 Instance와 `Renderer::Get()`
- Render Command 저장소: `std::vector<RenderCommand>`
- Command별 데이터: World Matrix
- Vertex Shader Constant Buffer Slot: `b0`
- Draw 순서: Transform Buffer 갱신 → `DrawIndexed()`

---

## Issue

- 현재 코드에서 `Renderer::Submit()`을 호출하는 위치가 확인되지 않아 Render Command 목록이 비어 있으며 Draw Call이 실행되지 않는다.
- `renderCommandList`를 Frame 처리 후 비우는 코드가 없어 매 Frame 제출을 시작하면 이전 Command가 누적될 수 있다.
- `Engine::Draw()`가 Clear Color로 `100.0f`, `200.0f`, `0.0f`를 전달한다. Direct3D Clear Color의 일반적인 범위인 `0.0f`부터 `1.0f`를 벗어난다.
- `Sleep(1)` 기반 대기 구간이 비활성화되어 Frame 제한 중 Busy-wait가 CPU를 계속 점유한다.
- `CreateTansformBuffer`, `UpdateTrnasformBuffer` 함수 이름에는 `Transform` 철자 오류가 남아 있다.
- 현재 Render Command에는 World Matrix만 있으며 View·Projection Matrix는 포함되지 않는다.
